# Simulador de Recebimento de Antena
## Descrição do Problema
Este script calcula a potência de sinal recebida por uma antena de rádio dependendo da distância da torre transmissora e da potência emitida.
## Requisitos
- Calcular a atenuação do sinal em dB com base na distância.
- Determinar se o sinal é forte, fraco ou inexistente.
## Exemplo de Uso
Entrada: Potência 100W, Distância 50km
Saída: Sinal Fraco (35.0 dB)
